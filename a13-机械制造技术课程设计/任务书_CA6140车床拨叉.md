# 机械制造技术课程设计任务书

## 1. 任务名称

**CA6140 车床拨叉零件的机械加工工艺规程及专用钻床夹具设计**

本任务以文件夹中的 CA6140 车床拨叉零件图为设计依据，完成从零件工艺分析、毛坯选择、工艺路线制定到专用夹具设计和 CAD 出图的完整课程设计。

> 本文件是基于现有零件图和说明书模板整理的工作版任务书。教师下发的正式任务书、零件图纸和现场要求优先于本文档。所有最终尺寸、配合和形位公差必须回到 PDF 原图逐项核对。

## 3. 零件与技术要求

### 3.1 零件功能

拨叉用于车床变速操纵机构，通过叉脚拨动齿轮或滑套完成换挡。设计时应关注：

- 叉轴孔与配合轴之间的尺寸精度和同轴/位置关系；
- 锁销孔与叉轴孔之间的位置关系；
- 叉脚工作面、操纵槽和端面的尺寸精度、表面粗糙度及形位公差；
- 铸铁件的刚度、加工变形和装夹可靠性。

### 3.2 图纸信息核对清单

以下是从图纸中可辨识出的主要标注，CAD 建模前必须在 PDF 原图上逐项放大确认：

| 类别 | 图纸中可见标注 | CAD/工艺处理要求 |
|---|---|---|
| 材料 | HT200 | 毛坯方案、切削参数和热处理说明均以此为基础 |
| 基准 | 基准 A | 在零件图、工序图和夹具图中统一标识 |
| 直径/轮廓 | `φ40`、`φ50`、`φ55±0.5` 等 | 以 PDF 原图的尺寸线和视图对应关系为准 |
| 孔 | `φ22` 带公差标注、`φ8`、`M8` | 明确孔的加工顺序、定位基准和刀具路线 |
| 圆角 | `R5` 等 | 铸造圆角与机械加工圆角不得混用 |
| 角度/位置 | `55°`、`60-0.2` 等 | 在 CAD 中建立基准中心线和角度约束 |
| 厚度/槽宽 | 图纸中带上下偏差的厚度、槽宽标注 | 在工序尺寸链中进行余量和公差分配 |
| 表面粗糙度 | `Ra 3.2`、`Ra 1.6`、`Ra 6.3` 等 | 在工艺卡中对应到具体工步 |
| 形位公差 | 对基准 A 的垂直度/位置度框格 | 作为定位误差和夹具精度校核依据 |

> 说明：本表只用于建立核图清单，不替代原始工程图。任何在低分辨率预览中无法确定的上、下偏差或直径归属，都必须以 PDF 原图为准后再写入 CAD 和说明书。

## 4. 设计内容

### 4.1 零件工艺分析

1. 分析拨叉的工作原理、主要工作表面和技术要求。
2. 判断零件结构特点、加工难点和可能的加工变形风险。
3. 确定主要定位基准、精基准和粗基准，并说明基准选择理由。
4. 分析各加工表面的加工方法、经济精度和表面粗糙度可达性。

### 4.2 毛坯设计

1. 根据 HT200、结构形状和生产类型选择毛坯种类。
2. 确定铸造分型、加工余量、拔模斜度、圆角和清砂要求。
3. 绘制毛坯简图，标出主要毛坯尺寸、余量和基准。
4. 说明毛坯缺陷、铸造应力和后续加工的处理措施。

### 4.3 工艺路线设计

1. 拟定从毛坯到成品的完整加工路线。
2. 安排基准面、孔、端面、叉脚、槽和锁销孔的加工顺序。
3. 对关键工序给出机床、刀具、量具、夹具、切削液和检验方法。
4. 对关键工序说明定位、夹紧、加工方向和防错措施。
5. 编制机械加工工艺过程卡和主要工序卡。

### 4.4 工艺计算

说明书中至少完成以下计算：

- 加工余量和工序尺寸；
- 尺寸链与公差分配；
- 切削速度、进给量、背吃刀量和主轴转速；
- 基本时间、辅助时间和单件工时；
- 关键表面精度、粗糙度和形位公差的保证方法。

计算中使用的经验系数、标准表号和机床参数必须给出来源，不得只列最终数值。

### 4.5 专用钻床夹具设计

夹具对象为拨叉锁销孔的钻削工序，具体孔径和位置以零件图为准。设计内容包括：

1. 确定定位方案，说明限制的自由度和定位基准。
2. 进行定位误差分析，校核孔的位置度/垂直度要求。
3. 选择夹紧机构，计算或校核夹紧力，说明夹紧方向和受力路径。
4. 选择钻套、衬套、钻模板和标准夹具元件。
5. 确定夹具体结构、排屑空间、装卸方式和操作安全性。
6. 在夹具装配图上标注关键尺寸、配合、技术要求和检验基准。
7. 绘制夹具体零件图，并标注材料、热处理、表面粗糙度和加工要求。

## 5. CAD 出图任务

CAD 图纸是本次任务的核心交付物，至少包括：

| 图纸 | 要求 |
|---|---|
| 零件图 | 按 PDF 原图重建，视图、剖视、尺寸、公差、粗糙度、形位公差和材料信息完整 |
| 毛坯图 | 标出铸造毛坯轮廓、分型/浇注相关说明、加工余量和毛坯基准 |
| 工艺过程卡 | 工序号、工序名称、定位基准、设备、工装、检验要求齐全 |
| 主要工序卡 | 对关键工序给出加工内容、刀具、参数、尺寸和检验方法 |
| 夹具装配图 | 定位元件、夹紧元件、钻模板、钻套、夹具体、工件和剖视关系清晰 |
| 夹具体零件图 | 结构尺寸、孔系、配合、粗糙度、材料、热处理和技术要求完整 |

建议保存以下格式：

- 可编辑源文件：`DWG` 或 `DXF`；
- 交换/提交文件：`PDF`；
- 文件名使用统一前缀，例如 `CA6140_拨叉_零件图`、`CA6140_拨叉_夹具装配图`。

## 8. 验收标准

### 图纸准确性

- 所有尺寸、上下偏差、配合、粗糙度和形位公差与 PDF 原图一致。
- 基准 A、中心线、剖切符号、孔系和螺纹表达完整。
- 零件图与夹具图中的工件轮廓、孔径和定位基准相互一致。

### 工艺合理性

- 工艺路线符合 HT200 拨叉的结构特点和成批生产要求。
- 粗、精基准选择有依据，工序顺序能够保证关键尺寸和形位公差。
- 工艺计算可复核，设备、刀具和量具选择与加工内容匹配。

### 夹具可用性

- 定位可靠、夹紧不损伤工件，装卸方便，排屑和操作空间合理。
- 定位误差和夹具制造误差满足锁销孔的位置/垂直度要求。
- 装配图、夹具体零件图和说明书中的编号、尺寸和技术要求一致。

### 文档质量

- 说明书无模板示例题目残留，尤其不能出现“牛头刨床推动架”等无关零件名。
- 目录、页码、图号、表号、公式编号和参考文献可追溯。
- CAD 图和说明书经过导出 PDF 后逐页检查，无缺字、重叠、裁切或乱码。

## 9. 推荐工作顺序

1. 先在 CAD 中按 PDF 原图建立基准、中心线和关键轮廓。
2. 建立尺寸/公差核对表，确认所有不清晰的标注。
3. 完成零件工艺分析和毛坯方案。
4. 编制工艺路线、工序卡和工艺计算。
5. 以锁销孔工序为对象完成定位、夹紧和夹具误差分析。
6. 绘制夹具装配图、夹具体零件图和毛坯图。
7. 将计算结果和图纸信息回填说明书模板。
8. 导出 CAD/说明书 PDF，逐页检查后再提交。
