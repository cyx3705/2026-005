## 2. 零件工艺分析

### 2.1 功能与结构

拨叉用于车床变速操纵机构，通过叉脚拨动变速齿轮或滑套完成换挡。零件属于叉杆类铸件，结构由拨叉头、叉臂、叉脚/操纵槽和锁销孔组成。主要加工难点是：

1. 铸件毛坯形状不规则，粗基准选择会直接影响后续孔、面和叉脚的位置关系。
2. 叉轴孔是后续定位和尺寸链的重要基准，应优先保证孔径、轴线位置及与基准 A 的关系。
3. 叉脚工作面承受换挡冲击，需要保证两端面尺寸、平面度/垂直度和粗糙度。
4. 锁销孔与叉轴孔存在位置关系；A1 只确定其加工工序，A2 再完成该工序的专用夹具设计。
5. HT200 铸件应先清砂、去飞边并检查缩孔、气孔和裂纹，避免缺陷进入精加工阶段。

### 2.3 基准选择

- **粗基准**：优先选取铸件上面积较大、连续且余量较均匀的平面，同时利用外轮廓限制零件转动，保证第一次加工的基准面有足够余量。
- **精基准**：先加工基准 A 所在平面，再以基准 A 配合已加工的主孔或中心线定位后续叉脚、槽和锁销孔。
- **基准统一原则**：后续精加工尽量使用同一组基准，减少基准转换带来的位置误差。

## 3. 毛坯方案

### 3.1 毛坯类型

采用 HT200 灰铸铁砂型铸造毛坯。理由如下：

- 零件外形复杂、壁厚和叉脚过渡较多，不适合直接用棒料或板料加工；
- 铸铁减振性好，适合车床变速机构的叉类零件；
- 成批生产条件下，铸造毛坯材料利用率和综合成本较合理。

### 3.2 毛坯技术要求

1. 铸件清砂、去飞边，非加工表面不得有影响装配和定位的凸瘤。
2. 重点检查主孔周围、叉脚根部和薄壁过渡处的缩孔、裂纹、冷隔和严重气孔。
3. 毛坯图标出加工余量、铸造圆角、拔模方向和分型面；精确数值按铸造工艺标准及图纸尺寸确定。
4. 对关键加工面预留均匀余量，避免因单侧余量过大造成加工变形。

### 3.3 毛坯简图要求

毛坯 CAD 图应至少表达：

- 毛坯整体轮廓和分型线；
- 基准 A 的毛坯对应面；
- 主孔、锁销孔和螺纹孔的加工余量表示；
- 叉脚两端面、槽面和外轮廓的余量；
- 材料 HT200、铸造圆角、清砂和未注铸造公差说明。

| 工序 | 工序名称 | 定位基准 | 主要设备/工装 | 加工内容与目的 |
|---:|---|---|---|---|

| 10 | 粗铣基准 A 面 | 铸件粗基准面 | 立式铣床、面铣刀 | 建立第一精基准，去除主要面余量 |

| 90 | 钻底孔、攻 M8 螺纹 | 基准 A + 主孔 | 钻床、丝锥 | 加工螺纹孔，检查有效深度和通止规状态 |

### 4.1 路线合理性

- 先建立基准 A，再加工主孔，后续叉脚和孔系尽量使用同一组精基准。
- 主孔采用“底孔 - 粗镗 - 精镗/铰”的渐进加工，降低铸件孔位偏差对最终尺寸的影响。
- 叉脚和槽部安排在主孔精加工之后，使主孔轴线可作为后续位置关系的参考。
- 锁销孔在 A1 中只确定加工方法和工序位置；夹具定位、夹紧、定位误差和夹具图纸归入 A2。
- 攻 M8 螺纹安排在相关平面和孔系加工完成后，防止后续切削损伤螺纹。

## 5. 主要加工方法与精度保证

| 加工表面 | 推荐方法 | 精度保证要点 |
|---|---|---|
| 基准 A 面 | 粗铣后精铣 | 先保证平面连续性和支承稳定，再控制平面度/垂直度 |
| φ22 主孔 | 钻底孔、粗镗、精镗或铰 | 控制孔轴线相对基准 A 的位置，精加工留均匀余量 |
| 叉脚端面 | 粗铣、半精铣、精铣 | 两端面应统一基准，控制厚度和对基准 A 的形位关系 |
| 叉脚内圆弧/槽 | 立铣刀或成形铣刀分步加工 | 先粗后精，避免薄壁区域一次去除过多余量 |
| φ8 锁销孔 | 钻削，必要时扩/铰 | 孔径和位置关系以图纸为准，A2 对定位误差进行专项设计 |
| M8 螺纹孔 | 钻底孔、倒角、攻丝 | 底孔直径、垂直度和有效深度满足螺纹标准 |
| R5 等圆角 | 铸造圆角或成形铣削 | 区分未加工铸造圆角和机械加工圆角 |

## 6. 工序尺寸与余量计算底稿

### 6.1 计算原则

1. 毛坯尺寸 = 成品尺寸 + 各工序加工余量，并按毛坯公差取整。
2. 粗加工余量应覆盖铸造偏差、表面缺陷层和装夹找正误差。
3. 精加工余量应满足刀具最小切深和表面粗糙度要求，不能因余量过小而出现黑皮或断续切削。
4. 尺寸链计算以基准 A 和主孔中心线为主要环节，叉脚位置和锁销孔位置要单独列出误差来源。

### 6.2 可复核的示例计算

以下仅展示计算方法，最终值需替换为图纸确认后的尺寸、余量和机床参数。

#### 主孔 φ22 H7 类尺寸

若图纸确认主孔为 `φ22 0/+0.021`，可采用：

- 铸造孔/预孔：保留足够的镗削余量；
- 粗镗后孔径：约 `φ21.6 - φ21.8`；
- 精镗或铰削余量：按刀具和材料手册取 `0.15 - 0.25 mm` 直径余量；
- 终检：内径量具检查孔径，量规或三坐标检查轴线位置。

孔的具体预钻直径、粗镗直径和精加工余量应由机床、刀具和教材表格确定，本文不把示例值固化为最终工艺卡数据。

#### 面加工余量

设某平面毛坯单边余量为 `Z`，粗铣余量 `Z1`，精铣余量 `Z2`，则：

`Z = Z1 + Z2 + 铸造偏差修正量`

精铣余量应覆盖粗铣后的刀痕、变形和局部黑皮，最终按铸造等级和面宽计算。

## 7. 切削用量计算示例

以下参数用于说明书计算格式和 CAD/工艺卡的初始估算，最终参数必须依据所选机床档位、刀具样本和课程教材表格修正。

### 7.1 端面粗铣示例

取硬质合金面铣刀 `D=80 mm`，齿数 `z=6`，初选切削速度 `v=80 m/min`，每齿进给量 `fz=0.10 mm/z`：

`n = 1000v/(πD) = 1000×80/(π×80) ≈ 318 r/min`

机床取整后可选 `n=315 r/min`。

`vf = fz×z×n = 0.10×6×315 ≈ 189 mm/min`

若切削长度、切入和超程合计 `Lm=110 mm`：

`tm = Lm/vf = 110/189 ≈ 0.58 min`

### 7.2 φ8 钻孔示例

取高速钢麻花钻，初选 `v=20 m/min`，`f=0.15 mm/r`：

`n = 1000v/(πd) = 1000×20/(π×8) ≈ 796 r/min`

机床取整后可选 `n=800 r/min`，则：

`vf = f×n = 0.15×800 = 120 mm/min`

若有效钻削长度含切入、通孔和超程共 `L=30 mm`：

`td = L/vf = 30/120 = 0.25 min`

### 7.3 M8 攻丝示例

M8 粗牙螺距 `P=1.25 mm`。若初选攻丝速度 `v=5 m/min`：

`n = 1000v/(πd) = 1000×5/(π×8) ≈ 199 r/min`

攻丝进给应与螺距同步，即 `vf = P×n ≈ 249 mm/min`。攻丝底孔直径和有效深度按 M8 标准及图纸要求确定。
