# 正典与版本

## 1. 证据等级

| 等级 | 含义 | 使用规则 |
| --- | --- | --- |
| A | 原文直接陈述或直接发生的事实 | 后续设定不得无说明地推翻 |
| B | 能由至少两处原文互相支撑的世界观推导 | 可以用于连接两篇作品，但必须写明“推导” |
| C | 为未来故事服务的开放设定 | 可以替换；不得回写成“原作事实” |
| D | 待核对或互相矛盾的信息 | 保留问题，不强行统一 |

资料库中的条目在标题后用 `[A]`、`[B]`、`[C]`、`[D]` 标记；未标记的段落是整理说明，不是新增剧情。

## 2. 三份文件的关系

### `焦岸_中长篇小说.md` [A]

目前最完整的 `焦岸` 版本。四卷、十七节、尾声，包含子午号任务的完整因果链：出发、冷眠事故、政治命令延迟、石冢接触、子节点定着、返航与小满回信。

### `焦岸.md` [A/B]

同题压缩稿。它保留了“子午号日志 / 游荡营造者志 / 石冢 / 返航”这一核心骨架，但删去了长篇中的船员名单、政治分裂、远钟权限、莫罗的校准模型、子节点改造和小满的具体回信。它不是第三篇小说，而是同一作品的短篇表达；短篇中出现的数字与措辞可作为独立版本的叙事记录，不应拿来覆盖长篇细节。

### `蔚蓝深渊航海记.md` [A]

独立的海王星深层考察日志。它没有直接写出子午号、石冢或焦岸，但与 `焦岸` 共享太阳系、冷眠远航、航海日志传统和“探索必须带着记录归来”的价值取向。两篇作品可放入同一宇宙，具体年代和人物是否相连暂列为 B 级推导。

## 3. 引用格式

资料库采用：`[作品 / 卷或章节 / 关键词]`。

例如：`[焦岸长篇 / 第一卷·一 / 太阳焦线]`、`[蔚蓝 / 第六章 / 钻石雨]`。需要逐字核对时，再回到上一级目录中的原 Markdown 文件；本库不复制大段原文。

## 4. 冲突处理

1. 先判断是否只是叙述尺度不同，例如短篇把目标写成“约五百五十天文单位之外”，长篇给出具体观测点。
2. 若是删节造成的缺口，保留长篇细节，并在版本差异表说明短篇未展开。
3. 若事实真正冲突，使用 D 级“叙述者记录差异”，不替作者裁判。
4. 任何未来作品使用 C 级设定时，应在作品自己的附录写明“采用本库 C 级方案”。

## 5. 当前正典结论

- 两篇小说属于同一硬科幻底层物理的 **兼容作品集**，不是已被正文明确宣告的连续系列。
- `焦岸` 的长篇版本是人物与政治细节的主参考；短篇版本保留其文学压缩形态。
- `蔚蓝` 的具体远征队成员与后续社会影响尚未命名，可继续扩展，但不能擅自把其叙述者等同于许岑或其他已知人物。
