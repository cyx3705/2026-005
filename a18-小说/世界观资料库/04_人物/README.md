## 使用方式

- 新写人物前，先读 [人物与关系](人物与关系.md) 和对应角色页中的“不可误写”。
- 同一事件的多个角色页允许保留不同理解；人物志不把分歧整理成唯一的心理真相。
- 若写子午号返抵曙门港之后的故事，先把新事件放进“任务标准时”和“收件时”两条时间线，再补人物反应。

## 共同状态

`焦岸` 结尾时，子午号六人生还、莫罗死亡；他们尚未实际抵达曙门港，太阳系社会也未恢复稳定。小满在谷神星地下城收到了许岑的信。这不是大团圆，而是重新获得了可以继续谈话的条件。
