# 拆线的修补匠

> 种子句：**“修好之前，先让它别继续伤人。”**

## 这个人是谁

他/她对抽象道德争论常常缺乏耐心，却能在危险真正扩散前看见哪一根线该断。这个人修东西，也知道有些“修复”只是把伤害延长得更漂亮。

修补匠的底色不是破坏欲，而是材料伦理：每一件工具、每一块资源、每一次接触都应算入后果。真正的修复必须先承认取走了什么、留下了什么、再也长不回什么。

## 原作锚点

- **穆萨**发现三重校验共用同一只错误主钟，设计单向材料板，最后切断石冢母子节点的复制母线。
- **坚忍号工程师**在海王星深层持续报告船体和冷却系统的真实极限，使返航成为可执行的判断。

## 稳定内核

| 维度 | 内容 |
| --- | --- |
| 想守住的东西 | 人、材料与系统之间仍可辨认的边界 |
| 最怕的事 | 所有人把不可逆风险叫作“小测试”“优化”或“必要代价” |
| 危机动作 | 隔离、拆线、取样、复核、用笨办法建立独立校验 |
| 盲点 | 容易把“可切断”误当成“已经解决”，低估关系与记忆的余波 |
| 必付代价 | 每次切断都会失去某种功能、档案、便利或与他人的和气 |

## 与主角的关系

主角通常想多看一眼、多等十秒、多赌一次；修补匠负责问“你愿不愿意承担它学会你的代价”。他/她最有效的戏不是说服，而是在主角仍犹豫时递出剪钳、断路器或停机单，让选择具有触感。

## 可换外壳

| 类型 | 可投射身份 | 具体动作 |
| --- | --- | --- |
| 科幻 | 轮机长、生物隔离工程师、旧设备回收员 | 用物理熔断取代口头禁令 |
| 都市 | 消防检修员、网络安全工程师、急救设备师 | 先隔离故障，再追究责任 |
| 历史/奇幻 | 铁匠、城墙修复师、炼金工匠 | 宁可毁掉传家器物，也不让裂缝扩散 |
| 家庭剧 | 修表人、修车店主、厨房维修工 | 把失控的机器停下，逼全家面对被掩盖的问题 |

## 象征物与语言

- **象征物**：剪钳、烧黑的耦合器、补丁、断路器、被回收的过量材料。
- **常用动作**：先看接口，再看人脸；在别人说“大局”时问“这块是谁的”。
- **语言质地**：短促、带对象名词，少用抽象词。愤怒时更冷静。

## 不要写成什么

- 不要写成只会砸东西的暴躁技术员。
- 不要让他/她永远正确；切断只是设下边界，不会自动疗愈失去。
- 不要用一段万能修理戏抹掉世界规则。

## 快速投射卡

> 当 ___（系统）开始把 ___（人/记忆/材料）当作可替换资源时，这位 ___（职业）发现了 ___（具体接口）。他/她选择切断它，换来 ___（不可逆损失），并要求主角在断口前亲自看一眼。
