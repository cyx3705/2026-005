# 迟到的收件人

> 种子句：**“我收到了，但我不是你寄信时想象的那个人。”**

## 这个人是谁

他/她在主角的远方，常常只以地址、未读消息、缺席或一封迟来的回信出现。真正见面时，这个人拒绝成为主角道歉、牺牲或远行的终点。他/她承认信息抵达，却保留自己改变、拒绝和重新定义关系的权利。

这个种子可以很安静，但绝不能被动。延迟不是他的/她的性格缺陷，而是一种不被主角占有的时间。

## 原作锚点

- **小满**要求许岑不要只给未来写信，最后说自己不能替过去的自己原谅，却承认母亲终于作答。
- **温叙**以缺席逼黎安面对一个边界：她不能把温叙的名字投进不可撤回的外星识别包，再把那当作爱。
- **白塔城地址系统**的死亡提醒人：地址失效，不代表人自动消失；消息抵达，也不代表关系回到发送时。

## 稳定内核

| 维度 | 内容 |
| --- | --- |
| 想守住的东西 | 自己的时间、拒绝权和不被别人定义的现在 |
| 最怕的事 | 被写成某人的等待、遗憾、纪念碑或赎罪证明 |
| 危机动作 | 不立即回信、要求明确回答、改写收件地址、拒绝被代表 |
| 盲点 | 可能把不回答当作唯一的安全方式，错过真正可修复的关系 |
| 必付代价 | 让主角失望，也承认自己无法替过去的自己作答 |

## 与主角的关系

迟到的收件人最适合出现在主角以为剧情已经结束的时候。他/她不会替主角判决无罪，也不一定拒绝主角；重点是让主角明白，发信不是完成关系，抵达才刚刚开始。

如果这个角色死去，也应通过生前选择、缺席的边界或认识他/她的人留下作用，而不是用遗书替主角达成和解。

## 可换外壳

| 类型 | 可投射身份 | 具体动作 |
| --- | --- | --- |
| 科幻 | 外行星教师、迁徙城市的地址管理员、失联家属 | 把旧地址标为死亡，但保留人的转寄权 |
| 都市 | 成年子女、前伴侣、灾后社区组织者 | 对迟来的道歉说“我听见了，但需要时间” |
| 历史/奇幻 | 驿站女主人、战争幸存者、被放逐的继承人 | 退回封存多年的信，并要求来信者亲自到场 |
| 悬疑 | 被保护证人、失踪者的妹妹、档案里被误记的人 | 拒绝被调查者替自己叙述 |

## 象征物与语言

- **象征物**：未发送草稿、失效地址、延迟影像、转寄标记、未打开的私信。
- **常用动作**：把问题原样退回去，要求对方说清“为什么”。
- **语言质地**：不夸张，句子常留余地；“我不能替以前的我……”是这类人物的典型句法。

## 不要写成什么

- 不要把回信、见面或原谅写成主角的奖品。
- 不要把他/她写成永远沉默的谜；迟到的收件人必须拥有主动的拒绝或选择。
- 不要让死亡替他/她把所有复杂关系固定成温柔纪念。

## 快速投射卡

> 主角在 ___ 年后送达一封以为能结束关系的 ___（信/录音/遗物）。收件人已经成为 ___，他/她承认收到，却提出 ___（一个不允许主角回避的问题）。主角必须在没有即时原谅的情况下继续行动。
