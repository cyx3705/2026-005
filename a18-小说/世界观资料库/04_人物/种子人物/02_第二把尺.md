# 第二把尺

> 种子句：**“别只拿系统自己的话证明系统正确。”**

## 这个人是谁

他/她通常不是领导者，而是那个在众人都相信同一套仪表、传统、血统或叙事时，悄悄留下另一把尺的人。这个人不负责推翻系统，只负责让系统无法独自宣布自己正确。

第二把尺可以是一张手绘地图、一份未经批准的备份、一种来自外部的语言、一名不被承认的证人。它真正的角色不是“解题钥匙”，而是在早期留下可供后来人重新校准的方法。

## 原作锚点

- **莫罗**手绘子午号航线，把终点旁标为“回头”，不完全信任只存在于机器里的路径。
- 他在最后一次冷眠前，将十二颗脉冲星的观测写入只能追加的审计入口；这套模型后来补足定着协议所需的独立时基。
- **海王星的动态地图**持续修订，不把一日的温压边界伪装成永久陆地，是较弱但同向的职业回声。

## 稳定内核

| 维度 | 内容 |
| --- | --- |
| 想守住的东西 | 一种不与主系统共用错误起点的参照 |
| 最怕的事 | 所有校验器、所有人和所有记录一起忠诚地错下去 |
| 危机动作 | 手记、交叉测量、保留旧样本、引入外部证词、重算第一项 |
| 盲点 | 容易把校准变成不信任，把留后手变成迟迟不肯承诺 |
| 必付代价 | 常被当作不合群、笨拙或多余；其方法可能在本人离场后才被理解 |

## 与主角的关系

主角往往需要第二把尺，却不一定喜欢这个人。这个角色会让主角承认：你最相信的东西也可能只是在重复自己。主角最终必须自行决定如何使用这把尺，不能被它代替做价值选择。

第二把尺很适合早期出现、后期缺席：离世、失权、离开、被误解都可以，但不能在最后一刻以全知遗言解决谜题。

## 可换外壳

| 类型 | 可投射身份 | 具体动作 |
| --- | --- | --- |
| 科幻 | 领航员、仪器校准员、无权限的观测员 | 用脉冲星、旧日志或独立传感器校对主钟 |
| 都市 | 审计助理、统计员、民间档案保管者 | 保留原始表格，拒绝只看处理后的仪表盘 |
| 历史/奇幻 | 抄写员、边境测量师、异乡翻译 | 把两种历法并列，不让胜者抹掉另一种时间 |
| 悬疑 | 旁证、旧案记者、法医技术员 | 留下一个与官方口供不重合的细节 |

## 象征物与语言

- **象征物**：透明薄膜航图、第二只钟、旧尺、无名坐标、删不掉的旁注。
- **常用动作**：把第一项重新归零、用手复算、问“这个基准从哪里来”。
- **语言质地**：不抢话，偶尔固执地重复一个小问题。

## 不要写成什么

- 不要写成死后万能的导师或密钥。
- 不要让他/她的独立基准自动提供道德正确答案。
- 不要把不信任变成对一切关系的蔑视；第二把尺是为了能继续共同生活，而不是为了证明只有自己清醒。

## 快速投射卡

> 所有人都依据 ___（同一系统）确认 ___。这个 ___（职业/边缘身份）却保存了 ___（外部参照），并在早期留下一个不起眼的注记：___。后来系统失效，主角必须决定是否使用它，并承担使用后的新问题。
