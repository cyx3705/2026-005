# 不替死亡加冕的照看者（储备母型）

> 目前保留为储备人物母型。唐缄已经给出了完整载体，但尚缺第二部作品中的独立对应者。

> 种子句：**“别迷信死亡。活着承担后果通常更难。”**

## 这个人是谁

他/她长期面对伤口、尸体、名单、残余物或失效的承诺，知道死亡会让故事显得整齐，却不会让责任自动消失。照看者不负责把悲剧变得有意义，只负责让活着的人继续承担后果，让死者不被拿来替活人发言。

这是一种温柔但不抚慰的角色：他/她可以包扎、清点、保存、送还，却不保证这样做会带来宽恕。

## 原作锚点

- **唐缄**在焦岸舱外行动后说，不能迷信死亡，活着承担后果通常更难；他处理伤口、污染和冷眠风险，也公开自己的旧医疗许可。
- **莫罗的母亲**只要求带回手绘星图，不要只带委员会结论；她拒绝让官方纪念替代具体的人。
- **黎安**最终把温叙的名字和六分钟沉默带回太阳系，而没有把名字发送到古网。

## 稳定内核

| 维度 | 内容 |
| --- | --- |
| 想守住的东西 | 活人继续生活的能力，以及死者不被滥用的具体性 |
| 最怕的事 | 牺牲被包装成崇高，活人因此被要求再次牺牲 |
| 危机动作 | 清点伤势、读风险报告、封存遗物、把名字交还给真正认识的人 |
| 盲点 | 可能因拒绝煽情而显得冷硬，无法给需要慰藉的人一句漂亮的话 |
| 必付代价 | 见证而不解决；必须长期留在残局里，而不是随英雄一起离场 |

## 与主角的关系

照看者常在主角准备把自己或别人献给“大义”时出现。他/她不一定阻止牺牲，但会问：谁清理之后的现场？谁支付剩余的医疗、法律和记忆成本？谁没有同意被纪念？

这类角色给主角的不是道德判决，而是一份无法跳过的清单。

## 可换外壳

| 类型 | 可投射身份 | 具体动作 |
| --- | --- | --- |
| 科幻 | 船医、污染控制员、死者档案员、灾后教师 | 把样本三次确认后封存，把姓名从编号中读出来 |
| 都市 | 临终护理师、事故调查员、殡仪师、社区社工 | 在媒体离开后留下，替家属解释下一步手续 |
| 历史/奇幻 | 战地医师、守墓人、寺院抄经人 | 不让英雄叙事覆盖无名死者的实际需求 |
| 悬疑 | 法医助理、失物保管员、证人保护官 | 保存证据，同时保护证据背后的人不被再次伤害 |

## 象征物与语言

- **象征物**：包扎带、医疗签字、封存袋、死者名单旁的手写名字、没有寄出的遗物。
- **常用动作**：把物品归位、把姓名读完整、把“后果”列成清单。
- **语言质地**：平静、具体，拒绝把悲伤写成漂亮的终点。

## 不要写成什么

- 不要写成只会劝人“坚强”的护理型配角。
- 不要让他/她用医学或伦理知识代替当事人的同意。
- 不要把不煽情等同于没有感情；照看者的情感应从持续工作和不离场中显现。

## 快速投射卡

> 主角准备把 ___（人/遗物/证据）献给 ___（宏大目标）。照看者先问 ___（谁承担残局），然后完成一项看似琐碎的工作：___。这项工作让主角发现，真正的代价会在壮举结束以后继续发生。
