# 种子人物

> 种子人物是作者级的“同一个人”，不是设定内同名、同血缘或同意识的角色。它可以在不同作品里换年龄、性别、职业、阵营、时代和结局，但会反复以同一种欲望、缺口、危机反应和象征位置出现。

## 与人物档案的区别

| 人物档案 | 种子人物 |
| --- | --- |
| 记录某个角色已经发生的事 | 规定一种角色可以在未来反复发生的方式 |
| 服从作品正典 | 服务于作者的跨作品一致性 |
| 不能擅自补全空白 | 主动保留可变的外壳 |
| 例如：穆萨 | 例如：拆线的修补匠 |

## 五个核心种子

| 种子 | 核心句 | 现有锚点 | 最适合承担的戏剧功能 |
| --- | --- | --- | --- |
| [回头路的守门人](01_回头路的守门人.md) | “先告诉我，哪一条路还能回来。” | 叶峤、杜瓦尔 | 给冒险保留退出权，不替主角作决定 |
| [第二把尺](02_第二把尺.md) | “别只拿系统自己的话证明系统正确。” | 莫罗、持续修订的航图 | 留下独立基准，不留下道德答案 |

## 使用方法

一名种子人物至少要有四项稳定内容：

1. **要守住什么**：不是职业目标，而是无法轻易放弃的价值。
2. **最怕重演什么**：不必先写成完整创伤史，但要让它影响选择。
3. **危机时的动作**：一个具体动作，比一段履历更能让种子复活。
4. **绝不替主角完成什么**：种子人物必须能推动主角，却不能抢走主角的决定。

每次投射时，至少换掉两项外壳：职业、年龄、关系、立场、阶层、世界规则、结局。只保留核心，避免把种子变成换名字的复制人。

## 配置原则

- 一部短篇最多放入 2 至 3 个核心种子，长篇最多放入 4 个；五个同时出现会把人物写成作者自我复读。
- 同一部作品中，`回头路的守门人`与`持钥的见证人`适合对照，`拆线的修补匠`与`低灯的气象员`适合协作，`迟到的收件人`与`不替死亡加冕的照看者`适合在结尾拆解主角的自我感动。
- 若一个角色同时承载两个种子，必须让两种核心相互冲突。例如，持钥的人也想守回头路时，他会在“留下记录”与“允许撤回”之间付出实际代价。

## 种子检查

写完一个新角色后，问四个问题：

- 拿掉姓名和职业后，仍能认出他/她属于哪个种子吗？
- 他/她有没有一个会损害自身利益的边界？
- 他/她是否只服务主角，还是也有独立的拒绝与选择？
- 他/她的象征物是否参与行动，而不只是装饰？
