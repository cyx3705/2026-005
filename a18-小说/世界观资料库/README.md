# 《沉默航线》宇宙档案

> 工作标题，不属于两篇小说正文的新增署名。
>
> 现有产出：`焦岸`、`蔚蓝深渊航海记`。

这是一个围绕“远行、记录、延迟和边界”建立的共享世界观资料库。它的任务不是替原作续写或改写，而是把两篇已经完成的小说放进一张可继续扩展的背景图中：海王星深层考察提供近太阳系的航天经验，子午号前往焦岸的任务把同一文明推到五万多天文单位之外，并让人类撞上一套已经失去收件人的古老网络。

## 资料库边界

- 原有三份 Markdown 原文保留在本目录上一级，未搬移、未重写、未覆盖。
- `焦岸.md` 是 `焦岸_中长篇小说.md` 的压缩版本，不作为第三篇独立小说处理。
- 原文明确写出的事实、数字和结局标为 **A 级正典**；根据原文作出的合理连接标为 **B 级推导**；为未来创作预留的内容标为 **C 级可选设定**。
- 若新设定与正文冲突，以正文为准；若两版 `焦岸` 之间有差异，以版本差异表记录，不擅自“修订”原稿。
