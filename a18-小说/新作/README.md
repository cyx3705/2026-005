## 《潮窗》设定边界

- **苇港**、**临潮站**、**岸址网**、**北堤潮门**和**雁序浮校**都是为本篇新增的局部地点/机构，不代表完整的地球政治地图。
- 回潮来自风暴增水、上游泄水和旧河道工况叠加，不是天文潮汐突然改变。
- 岸址网是水上地址、补给和通行路由系统；地址失效不等于居民死亡、失联或放弃权利。
- 本篇不判定战争起因，不补全地球政体，不改变白塔城、子午号和停火议庭在原作中的结果。
- 结尾的人员状态只按现场可见信息记录，保留未知和拒绝转泊；档案损失、权限追责与职业后果均真实存在。
